# titanic-analysis

## descripcion del proyecto
este proyecto realiza un analisis exploratorio de datos (eda), limpieza, tratamiento de valores faltantes, ingenieria de caracteristicas y generacion de visualizaciones a partir de la informacion demografica y de transporte de los pasajeros del titanic.

## dataset
- **nombre del dataset:** titanic - machine learning from disaster (`train.csv`).
- **fuente:** kaggle (titanic dataset).
- **descripcion breve:** contiene informacion demografica, socioeconomica y de viaje de los pasajeros a bordo del rms titanic, incluyendo datos como edad, sexo, clase de boleto, tarifa, cabina, puerto de embarque y estado de supervivencia.

## objetivo
el objetivo principal es analizar los factores clave que determinaron las probabilidades de supervivencia de los pasajeros del titanic mediante la exploracion de patrones, el tratamiento adecuado de datos nulos y la creacion de nuevas variables explicativas.
